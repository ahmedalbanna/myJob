# معمارية مشروع "وظيفتك"

هذا الملف يمثل "عقل المشروع" لمساعدة نماذج الذكاء الاصطناعي على فهم البنية، الأهداف، وقواعد تطوير تطبيق "وظيفتك".

## 1. هدف التطبيق
منصة "وظيفتك" هي سوق رزق رقمي يهدف لربط الشباب اليمني بفرص العمل (حكومية، قطاع خاص، منظمات، عمل حر) وتوفير إرشاد مهني صوتي شامل.
- **القيمة الأساسية:** معالجة بطالة الشباب، ربط المهارات بسوق العمل، توفير التوجيه، وإتاحة التقديم الميسر (صوتياً) دون تعقيدات ورقية.

## 2. هيكلية الملفات
- `/src/`: المجلد الرئيسي للكود المصدري.
- `/src/components/`: المكونات التفاعلية القابلة لإعادة الاستخدام (Sidebar, Header, إلخ).
- `/src/pages/`: صفحات التطبيق الرئيسية (Dashboard, Jobs, Profile, Guidance, Projects, JobDetails).
- `/src/data.ts`: البيانات النموذجية (Mock Data) للنظام.
- `/src/types.ts`: تعريفات الأنواع (TypeScript Interfaces).
- `/src/index.css`: التنسيقات العالمية (Tailwind + الخطوط).

## 3. قواعد البرمجة
- **اللغة:** TypeScript (صرامة عالية في التعريفات).
- **إدارة الحالة:** معالجة بسيطة باستخدام `useState` في المكونات (سيتم الترقية لـ Zustand عند التعقيد).
- **التنسيق:** Tailwind CSS (Mobile-first, تصميم مخصص غير افتراضي).
- **التفاعل:** Hooks مخصصة (عند الحاجة)، مع التركيز على سهولة الوصول.
- **التنوي:** الخطوط المستخدمة هي "Tajawal" للعربية، مع أنظمة ألوان مخصصة (Primary: أخضر وظيفتك التنموي).
- **النهج:** تصميم واجهات "مطور محترف"، التزام بمعايير SOLID في معمارية المكونات.

## 4. سجل القرارات
- **قرار:** استخدام واجهة "التقديم الصوتي" كسمة تميز التطبيق ليتناسب مع الطبيعة الثقافية والتقنية للمستخدم اليمني (شامل للأمي والمتعلم).
- **قرار:** دمج كل صفحات التوظيف (الفرص، التقديم، الإرشاد) في تطبيق ويب واحد (SPA) يعتمد على `App.tsx` كمنظم للمشاهد.
- **قرار:** الاعتماد على Tailwind CSS فقط للتصاميم لضمان خفة التطبيق وسرعة التحميل.
